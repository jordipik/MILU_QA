Experimental: Hybrid OCR + Geometric Parser\n\n**Motivation**: Actual OCR puede proporcionar confidence scores per token.\n\n**Proposed**:\n- Integrar Tesseract.js o similar para OCR confidence\n- Para tokens \"uncertain\" (low confidence), usar contexto geométrico para validar\n- Aplicar ML classifier simple (Naive Bayes?) para decidir columna cuando geometría es ambigua\n\n**Scope**:\n```javascript\nfunction assignRectToColumnHybrid(rect, columns, ocrConfidence) {\n    // Geometric assignment (baseline)\n    const geometricAssignment = getColumnByGeometry(rect, columns);\n    \n    if (ocrConfidence < 0.6) {\n        // Low OCR confidence - use context\n        return classifyByContext(rect, geometricAssignment, bodyRects);\n    }\n    \n    return geometricAssignment;\n}\n```\n\n**Estimate**: 8-10 horas\n**Risk**: Adds dependency, potential performance regression\n\n### 4. Multi-page Table Fusion\n\n**Current**: Cada página parseada independientemente.\n\n**Proposed**:\n1. Detectar \"continued from previous page\" signals\n2. Fusionar rows consecutivos de páginas adjacentes\n3. Validar coherencia (ej: POS numbers should be sequential)\n\n**Algorithm**:\n```javascript\nfunction tryFuseMultipage(pages) {\n    const fused = [pages[0].rows];  // Start with page 1\n    \n    for (let i = 1; i < pages.length; i++) {\n        const prevPage = pages[i-1];\n        const currPage = pages[i];\n        \n        // Check if currPage headers match prevPage\n        if (columnsCompatible(prevPage.columns, currPage.columns)) {\n            // Fusionar rows\n            fused.push(...currPage.rows);\n        } else {\n            // Different structure, keep separate\n            break;  // Stop fusion attempt\n        }\n    }\n    \n    return fused;\n}\n```\n\n**Estimate**: 6-8 horas\n**Impact**: Support catalogs > 1 page\n\n### 5. Template Learning (Per-Manufacturer)\n\n**Motivation**: Diferentes fabricantes (GESA, FG, FGS) tienen layouts predecibles.\n\n**Proposed**:\n- Detectar \"manufacturer signature\" (logo text, header format)\n- Cargar template específico (ratios pre-tuned)\n- Usar en lugar de generic template\n\n**Data Structure**:\n```javascript\nconst MANUFACTURER_TEMPLATES = {\n    gesa: {\n        name: 'GESA Motors',\n        headerPattern: /gesa|motor/i,\n        columnRatios: [0.0, 0.045, 0.09, 0.22, ...],  // GESA-specific\n        confidence: 'high'\n    },\n    fg: {\n        name: 'FG Spare Parts',\n        headerPattern: /FG|spare/i,\n        columnRatios: [0.0, 0.05, 0.10, 0.25, ...],  // FG-specific\n        confidence: 'medium'\n    }\n};\n```\n\n**Estimate**: 4-6 horas\n**Benefit**: Better defaults, faster convergence\n\n## Long Term (3-6 months)\n\n### 6.
